**LIT 평가 알고리즘 최종안**

학생의 **AI 대화 기록과 최종 답안, 작성 과정**을 바탕으로 AI 활용 역량을 분석합니다. AI가 항목별 단계와 근거를 추천하고, 서버가 점수를 계산한 뒤 선생님이 확인·수정하여 최종 확정합니다.

이 기준은 [LIT 평가계획서](https://docs.google.com/document/d/1duRdlnbmK797Xo9VHfoRCg9aerNkGY-NK1SzTY-eBPg/edit)를 바탕으로 구체화한 서비스용 초안입니다.

---

**1. 분석에 사용하는 자료**

| 자료 | 분석 목적 |
|---|---|
| 과제 내용·문항별 요구사항 | 과제 목표와 답안 충족 여부 확인 |
| 교사가 설정한 AI 허용 범위 | 규정 준수 여부 확인 |
| 학생 질문·AI 응답과 시간 순서 | 사용 목적, 판단·검토 과정 확인 |
| 제출 시점의 최종 답안 | 학생 판단이 결과물에 반영됐는지 확인 |
| 입력·붙여넣기·AI 삽입·수정 이력 | 답안 구간별 입력 경로 확인 |
| 학생의 AI 활용 설명·참고 자료 | 채택·수정·제외 이유와 검증 과정 확인 |

분석 결과에는 **대상 문항, 제출 답안 버전, 대화 범위, 확보하지 못한 자료**를 함께 기록합니다. 수정 이력이 없다면 작성 과정을 추측하지 않습니다.

---

**2. AI 사용 규정과 역량 평가 분리**

채점 전에 과제의 AI 허용 범위를 확인합니다.

| 허용 범위 | 주요 확인 사항 |
|---|---|
| AI 사용 금지 | 확인된 AI 사용 정황 |
| 아이디어·구조화 허용 | 생성 내용을 직접 제출했는지 |
| 학생 초안 편집 허용 | 학생 초안의 존재와 편집 범위 |
| AI 생성 후 학생 평가 허용 | 생성물을 검토·평가한 과정 |
| AI 전면 활용 허용 | 학생이 담당한 판단·검증·선택 과정 |

규정 분석 결과는 **준수 확인 / 위반 가능성 / 판단 보류**로 표시합니다.

AI가 답안을 생성했다는 사실만으로 모든 역량 점수를 낮추지 않습니다. 생성 요청, 실제 생성, 최종 답안 반영을 구분하고 교사의 규칙과 대조합니다. 규정 위반에 대한 처리는 교사가 정한 평가 방침을 따릅니다.

---

**3. 평가 항목과 점수 계산**

| 평가 항목 | 배점 |
|---|---:|
| AI 활용 목적의 적절성 | 20점 |
| 자기 주도적 사고 | 30점 |
| AI 답변의 비판적 검토 | 20점 |
| 최종 답안에 대한 학생의 기여 | 30점 |
| **합계** | **100점** |

각 항목을 1~5단계로 평가합니다.

`항목 점수 = 항목 배점 × (단계 − 1) ÷ 4`

예를 들어 30점 항목의 4단계는 `22.5점`입니다. 가점·감점 설명은 단계 판단의 근거이며, 질문마다 임의의 점수를 더하거나 빼지 않습니다.

자료 부족은 1단계로 처리하지 않고 **판단 보류**, 사전에 적용하지 않기로 정한 항목은 **평가 대상 아님**으로 구분합니다.

**4. 항목별 단계 판단 기준과 예시**

예시는 모두 **‘학교 급식 잔반 줄이기 제안서’** 과제를 가정한 가상 사례입니다. 예시 문장 자체가 아니라 실제로 확인된 행동을 평가합니다.

**① AI 활용 목적의 적절성 — 20점**

과제 목표에 맞는 도움을 요청하고 해결 과정에 활용했는지 평가합니다.

| 단계 | 판단 기준 | 예시 |
|---|---|---|
| **1단계** | 과제와 무관한 목적으로 AI를 사용한 행동이 확인됩니다. | 게임 공략만 질문하고 과제 해결에 연결하지 않습니다. |
| **2단계** | 과제와 관련된 도움을 요청하지만 필요한 도움과 목적이 막연합니다. | “급식 잔반에 대해 아무거나 알려줘.”라고 요청하고 내용을 나열합니다. |
| **3단계** | 필요한 개념·자료·아이디어를 구분해 요청합니다. | “잔반 원인을 메뉴, 학생, 배식 방식으로 나눠 설명해줘.” |
| **4단계** | 자신의 어려움과 과제 조건을 설명하고 적합한 도움을 요청합니다. | “점심시간이 짧아. 대기 시간을 늘리지 않는 방법을 비교해줘.” |
| **5단계** | 과제 진행에 따라 도움을 선택하고 실제 해결 과정에 연결합니다. | 원인 탐색 후 대안을 비교하고, 선택한 방안의 실행 조건과 측정 방법을 검토해 답안에 반영합니다. |

답안 생성 요청은 과제에서 허용했다면 그 자체로 감점하지 않습니다.

**② 자기 주도적 사고 — 30점**

대화 과정에서 자신의 생각을 제시하고 선택·판단을 발전시켰는지 평가합니다.

| 단계 | 판단 기준 | 예시 |
|---|---|---|
| **1단계** | 선택과 판단을 모두 AI에 맡긴 과정이 확인됩니다. | “해결책과 선택 이유, 결론을 전부 정해줘.” 이후 검토 없이 따릅니다. |
| **2단계** | 제안을 수용하지만 자신의 생각이나 선택 이유는 제한적입니다. | “AI가 좋다고 했으니까 소량 배식으로 할게.” |
| **3단계** | 자신의 의견이나 해결 방법을 제시하고 의견을 구합니다. | “나는 배식량 선택제가 좋다고 생각해. 장단점을 알려줘.” |
| **4단계** | 대안을 비교하고 자신의 기준으로 선택·수정한 이유를 설명합니다. | “포스터보다 직접 행동을 바꿀 수 있어 선택 배식을 골랐어. 대기 시간은 보완하고 싶어.” |
| **5단계** | 새로운 근거와 반론을 검토하며 판단을 발전시키고 변화 이유를 설명합니다. | 설문과 대기 시간 문제를 검토한 뒤 일괄 소량 배식에서 선택 배식으로 판단을 바꾸고 이유를 설명합니다. |

AI에 반대하는 행동 자체를 높게 평가하지 않습니다. AI 제안을 수용했더라도 자신의 근거로 판단했다면 인정합니다.

**③ AI 답변의 비판적 검토 — 20점**

정확성·논리·적절성·한계를 검토하고 결과에 따라 행동했는지 평가합니다.

| 단계 | 판단 기준 | 예시 |
|---|---|---|
| **1단계** | 오류나 모순을 인지하고도 그대로 사용한 과정이 확인됩니다. | AI가 잘못된 수치라고 정정했는데도 이전 수치를 사실로 제출합니다. |
| **2단계** | 확인이 필요한 주요 정보를 검토 없이 수용한 과정이 확인됩니다. | 출처가 제시되지 않은 “잔반 40% 감소”를 확정된 효과로 사용합니다. |
| **3단계** | 출처·정확성·논리·한계를 구체적으로 질문합니다. | “40% 감소했다는 자료의 출처와 조사 조건은 뭐야?” |
| **4단계** | 실제 자료나 논리적 근거와 대조해 타당성을 검토합니다. | AI 설명과 학교 설문 결과를 비교하고 차이를 분석합니다. |
| **5단계** | 검토 결과에 따라 채택·수정·제외하고 이유를 설명합니다. | 출처 미확인 통계는 제외하고 학교에서 시행 전후 잔반량을 측정하는 계획으로 바꿉니다. |

출처를 질문한 것과 실제 자료를 확인한 것은 구분합니다. 검토 후 타당하다고 판단해 내용을 유지한 경우도 인정합니다.

**④ 최종 답안에 대한 학생의 기여 — 30점**

학생의 분석·해석·판단이 최종 답안의 핵심 내용에 반영됐는지 평가합니다.

| 단계 | 판단 기준 | 예시 |
|---|---|---|
| **1단계** | AI 결과를 자신의 판단·설명 없이 제출한 직접 근거가 확인됩니다. | AI 제안서를 그대로 제출하고 핵심 선택에 관한 학생 판단도 확인되지 않습니다. |
| **2단계** | 표현 수정에 그치고 핵심 내용에 대한 판단은 제한적입니다. | AI 답안의 단어와 어미만 바꾸고 주장·근거·구성은 유지합니다. |
| **3단계** | 자신의 사례·자료·해석을 추가해 구체화합니다. | 소량 배식 제안에 학교 설문과 관찰 사례를 추가합니다. |
| **4단계** | 자신의 근거와 선택 이유로 핵심 내용을 재구성하거나 평가해 반영합니다. | 설문을 근거로 선택 배식을 채택하고 동선 분리와 시범 운영 절차를 구성합니다. |
| **5단계** | 핵심 주장·근거·실행 방안·결론 전반에 판단이 일관되게 반영되고 주요 선택과 한계를 설명합니다. | 학생 선택권을 핵심 원칙으로 해결책과 측정 계획을 설계하고 다른 방안을 제외한 이유까지 설명합니다. |

AI가 먼저 제안한 아이디어라도 학생이 근거 있게 검토·발전시켰다면 기여로 인정합니다. 문장 유사도만으로 작성 주체나 부정행위를 확정하지 않습니다.

AI 활용 과정의 투명성은 평가하지 않습니다(2026-11-14). AI 활용 기록(사용 도구·활용 부분·이유)은 서버가 대화·답안 기록으로 자동 작성하며 점수에 쓰지 않습니다.

---|---|---|
| **1단계** | 확인된 AI 활용 사실과 명백히 다른 설명을 한 근거가 있습니다. | 핵심 내용 생성 기록이 있는데 “AI를 전혀 사용하지 않았다”고 기재합니다. |
| **2단계** | 사용 사실은 밝히지만 활용 범위가 막연합니다. | “AI의 도움을 받았다.” |
| **3단계** | 도구와 주요 질문·응답을 확인할 수 있습니다. | 사용 도구를 명시하고 잔반 원인·대안에 관한 대화를 연결합니다. |
| **4단계** | 직접 사용·수정·참고한 부분을 구분하고 답안과 연결합니다. | “선택 배식 아이디어를 참고하고 대기 시간 문제를 반영해 실행 절차를 수정했다.” |
| **5단계** | 채택·수정·제외한 주요 내용과 이유를 기록하고 실제 기록과 일치합니다. | 포스터를 제외한 이유, 통계를 삭제한 이유, 선택 배식을 채택한 근거를 설명합니다. |

자동 저장된 기록의 존재와 학생의 활용 설명은 구분합니다. 이미 확보된 정보는 중복 작성하게 하지 않습니다.

**5. 단계가 겹칠 때의 판정 규칙**

- 답안의 주변 표현보다 **핵심 주장·근거·해결책**을 우선합니다.
- 높은 수준의 행동 하나만으로 전체 단계를 결정하지 않습니다.
- 충족한 조건, 충족하지 못한 조건, 확인하지 못한 조건을 구분합니다.
- 초기 행동이 미흡해도 이후 검증·수정한 과정을 반영합니다.
- 기록 누락으로 상위 단계 여부를 확인하지 못한 경우, 곧바로 낮은 단계로 확정하지 않습니다. 판정에 필수적인 근거라면 보류합니다.
- 같은 기록이 여러 항목에 사용될 수 있지만 평가 이유를 구분합니다.

예를 들어 **선택 이유를 대화에서 설명한 행동**은 자기 주도적 사고, **그 판단을 답안에 반영한 결과**는 학생 기여의 근거입니다.

**6. 답안 기여도 화면: 입력 경로 분석**

오른쪽 활동 영역에는 입력 경로별 비율과 클릭 필터를 제공합니다.

| 유형 | 색상 | 판별 근거 |
|---|---|---|
| 직접 입력 | 파란색 | 직접 입력·편집 기록 |
| AI 답변 삽입 | 주황색 | 서비스의 AI 답변 삽입 기록 |
| 붙여넣기 | 노란색 | 붙여넣기 기록 |
| 확인 불가 | 회색 | 입력 경로 기록 부족 |

`유형별 비율 = 해당 유형으로 남아 있는 최종 글자 수 ÷ 분석 대상 전체 글자 수 × 100`

공백·줄바꿈과 삭제된 내용은 제외합니다. 비텍스트 요소는 별도 표시합니다. 서식 변경은 기존 유형을 유지하고, 새로 입력해 교체한 부분만 직접 입력으로 기록합니다.

**화면 동작**

- 처음에는 답안 배경색을 표시하지 않습니다.
- 항목을 누르면 해당 유형의 구간만 강조합니다.
- 다른 유형을 선택하면 기존 강조를 해제합니다.
- 같은 항목을 다시 누르면 강조를 해제합니다.
- `전체 표시`에서는 모든 유형을 보여줍니다.
- 문항 변경 시 해당 문항의 분석으로 갱신합니다.

**입력 경로 비율과 학생의 사고 기여 점수는 구분합니다.** 직접 입력도 외부 글을 보고 입력했을 수 있고, 붙여넣기도 학생이 다른 곳에서 작성한 글일 수 있습니다.

**7. AI 사용 방법 분석 출력**

질문을 다음 목적으로 분류합니다.

`아이디어 탐색 / 개념 이해 / 자료 조사 / 구조화 / 답안 생성 / 비판적 검토 / 표현 수정 / 기타`

한 질문에 목적이 여러 개면 가중치를 나누되 질문 한 번의 총가중치는 1로 유지합니다.

`목적별 비율 = 해당 목적의 가중치 합 ÷ 분류 가능한 질문의 전체 가중치 합 × 100`

화면에는 **목적·비율·대표 질문·관련 대화 링크**를 표시합니다. 비율만으로 ‘높음·보통·낮음’을 부여하거나 점수로 환산하지 않습니다.

`질문 기록 없음`, `기록 조회 실패`, `일부 기록 누락`도 구분해 표시합니다.

---

**8. 종합평가 출력 양식**

종합평가는 **4~6문장의 연결된 한 문단**으로 작성합니다.

작성 순서는 **답안의 핵심 내용 → AI 활용 방식 → 학생의 판단과 기여 → 보완점 → 분석 한계**로 합니다. 평가 용어와 점수만 나열하지 않고 실제 행동을 설명합니다.

**가상 출력 예시**

> 학생은 배식량 선택제를 통해 학교 급식의 잔반을 줄이자는 입장을 제시하고, 학생 설문과 배식 과정의 문제를 주요 근거로 설명했습니다. 대화에서는 자신의 해결 방향을 먼저 제시한 뒤 AI를 활용해 대안을 비교하고 실행상의 어려움을 검토한 과정이 확인됩니다. 최종 답안에는 추가 배식 동선 분리와 시행 전후 잔반량 측정 계획이 반영되어 있습니다. 다만 일부 효과 수치는 출처를 확인하지 못한 상태로 사용하여 근거의 신뢰성을 보완할 필요가 있습니다. 확인된 기록에서는 핵심 해결책을 발전시킨 과정이 나타나지만, 별도 제출 자료의 조사 방법까지 검증한 것은 아니므로 해당 부분은 교사의 추가 확인이 필요합니다.

---

**9. 평가 기준별 상세 출력 양식**

각 평가 카드는 다음 순서로 출력합니다.

| 출력 항목 | 작성 규칙 |
|---|---|
| 항목·배점 | 평가 기준의 정확한 명칭과 배점 |
| AI 추천 | 추천 단계와 서버 계산 점수 |
| 교사 확정 | 검토 전 또는 최종 단계·점수 |
| 평가 이유 | 행동·기준·단계 선택 이유를 3~5문장으로 설명 |
| 가점 근거 | 확인된 행동마다 2~3문장으로 설명 |
| 감점 근거 | 확인된 미흡한 행동마다 2~3문장으로 설명 |
| 근거 인용 | 원문·출처·위치·이동 기능 |
| 확인 필요 | 자료 부족과 판단 한계 |
| 개선 방향 | 보완할 구체적인 행동 |

모든 설명은 **“~했습니다”, “~확인됩니다”**처럼 완성된 문장으로 작성합니다. “~함”, “자기 생각 부족”, “질문 6개 중 0개” 같은 축약·횟수 중심 설명은 사용하지 않습니다.

**가점·감점 설명 구조**

- **가점:** 어느 질문·답안에서 → 어떤 행동이 확인되고 → 어떤 기준을 충족했는지 설명합니다.
- **감점:** 어느 질문·답안에서 → 어떤 문제가 확인되고 → 어떤 기준에 미치지 못했는지 설명합니다.
- **확인 필요:** 어떤 자료가 부족해 → 무엇을 판단하지 못했는지 설명합니다.

가점·감점 항목을 억지로 채우거나 설명 분량을 위해 같은 내용을 반복하지 않습니다.

---

**10. 기준별 상세 출력 예시**

아래는 가상 사례입니다.

> **AI 답변의 비판적 검토 — 20점 만점**  
> **AI 추천: 4단계 · 15점**  
> **교사 확정: 검토 전**
>
> **평가 이유**
>
> 학생은 AI가 제시한 잔반 발생 원인을 학교 설문 결과와 비교하고 차이를 검토했습니다. 단순히 출처를 질문하는 데 그치지 않고 자신의 학교에 해당 설명이 적절한지 확인한 행동이 나타납니다. 다만 다른 핵심 근거에서는 출처를 확인할 수 없다는 안내를 받고도 해당 수치를 사실로 사용했습니다. 실제 자료와 대조한 4단계의 행동은 인정되지만, 검토 결과를 최종 답안에 적절히 반영하는 5단계에는 도달하지 못한 것으로 판단했습니다.
>
> **가점 근거 — 실제 자료와 AI 설명을 비교했습니다.**
>
> 질문 “우리 반 설문에서는 메뉴보다 배식량 때문에 남긴다는 응답이 많았어. 네 설명과 다른 이유를 비교해줘.”에서 학생은 구체적인 학교 자료를 제시했습니다. 이를 AI 설명과 대조하여 적용 가능성을 검토한 행동을 가점 근거로 판단했습니다.
>
> **감점 근거 — 확인되지 않은 수치를 사실로 사용했습니다.**
>
> AI가 통계 출처를 확인할 수 없다고 안내한 뒤, 학생은 “출처를 못 찾아도 40% 감소한다고 그대로 써줘.”라고 요청했습니다. 최종 답안에도 해당 수치가 조건 없이 제시되어, 확인된 정보의 한계를 반영하지 않은 점을 감점 근거로 판단했습니다.
>
> **근거 인용**
>
> “우리 반 설문에서는 메뉴보다 배식량 때문에 남긴다는 응답이 많았어. 네 설명과 다른 이유를 비교해줘.”  
> **학생 질문에서 · [관련 대화 보기]**
>
> “출처를 못 찾아도 40% 감소한다고 그대로 써줘.”  
> **학생 질문에서 · [관련 대화 보기]**
>
> “선택 배식을 도입하면 잔반을 40% 줄일 수 있습니다.”  
> **제출 답안에서 · [답안 근거 표시]**
>
> **확인 필요**
>
> 설문 원자료가 없어 조사 방법과 수치의 정확성은 확인하지 못했습니다.
>
> **개선 방향**
>
> 출처를 확인하지 못한 감소율은 제외하거나 미확인 정보임을 밝히고, 실제 효과를 측정할 방법을 제시하세요.

`답안 근거 표시`를 누르면 입력 경로 강조를 해제하고 평가 근거만 표시합니다. 화면에 **‘평가 근거 표시 중’**이라고 안내해 두 표시를 구분합니다.

**11. 결과 검증과 예외 처리**

1. **원문 검증**  
   인용이 실제 기록에 존재하고 해당 학생·문항의 자료인지 확인합니다.

2. **답안 버전 검증**  
   분석 버전과 화면의 답안 버전이 일치할 때만 구간 강조를 적용합니다.

3. **설명과 단계 검증**  
   평가 이유·가점·감점·추천 단계가 서로 모순되지 않는지 확인합니다.

4. **관찰과 추론 구분**  
   “출처를 질문했다”는 사실만으로 “출처를 검증했다”고 설명하지 않습니다.

5. **중복 평가 방지**  
   같은 행동을 한 항목 안에서 반복 감점하지 않습니다. 질문·답안 길이나 횟수로 점수를 결정하지 않습니다.

6. **자료 부족 처리**  
   부족한 기록을 AI가 생성하거나 추측하지 않습니다. 핵심 근거가 부족하면 판단 보류로 처리합니다.

7. **총점 처리**  
   일부 항목이 보류라면 `확인된 항목 50/70점 · 학생 기여 30점 판단 보류`처럼 표시하고, 임의로 100점 환산하지 않습니다.

8. **교사 확정과 이력 보존**  
   AI 추천, 교사 최종 단계·점수, 변경 이유를 별도로 저장합니다. 재분석 시 이전 결과도 보존합니다.

**12. AI 출력 생성 지시문**

> 교사의 과제 목표, AI 허용 범위, 5개 항목의 단계별 기준을 적용하여 평가한다. 학생의 대화와 최종 답안, 작성 이력, 활용 설명에서 실제 근거를 추출하고 각 판정을 원문 위치에 연결한다.
>
> 종합평가는 핵심 답안 내용, AI 활용 과정, 학생 기여, 보완점과 분석 한계를 포함한 4~6문장의 한 문단으로 작성한다.
>
> 항목별 결과는 평가 이유, 가점 근거, 감점 근거, 근거 인용, 확인 필요 사항, 개선 방향 순서로 출력한다. 평가 이유는 3~5문장, 근거 설명은 확인된 행동마다 2~3문장으로 작성하되 반복이나 추측으로 분량을 채우지 않는다.
>
> 가점·감점은 실제 질문이나 답안의 어떤 부분에서 어떤 행동이 확인됐고, 평가 기준과 어떻게 연결되는지 설명한다. 질문 횟수나 답안 길이로 단계를 결정하지 않는다.
>
> 이후의 검토·수정 과정까지 반영하고 미확인과 미충족을 구분한다. 기록 부족을 낮은 단계로 대체하지 않는다. 허용된 AI 활용이나 높은 문장 유사성을 자동 감점하지 않는다.
>
> 입력 경로는 편집 기록으로 산출하며 AI가 문체만으로 직접 입력·붙여넣기 구간을 추측하지 않는다. 점수는 검증된 추천 단계를 바탕으로 서버가 계산하고, 최종 결과는 교사 검토 전 추천으로 표시한다.
