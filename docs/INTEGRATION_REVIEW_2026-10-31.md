원본은 별도 작업 폴더에 풀어 보관했습니다. 압축의 `.git`, 실제 DB(`data`), 빌드 결과와 환경 비밀 파일은 가져오지 않았습니다. 현재 저장소의 Git 이력·DB·환경 설정을 유지하며 소스 변경만 통합했습니다. 압축에는 프런트 프로젝트가 없으며 이번 범위는 백엔드만입니다.

## 압축본과 달리 바로잡은 부분

- 기록이 없을 때 만점을 주지 않습니다. 추천 불가 항목·추천 가능 배점 합계를 응답에 포함합니다. 미확정 부분합을 확정 성적으로 표시하지 않습니다.
- 근거 없이 교육부·UNESCO 등의 공식 배점인 것처럼 표시하지 않습니다. 프로젝트 기본 제안안이며 운영 담당의 기준 확정이 필요합니다.
- 유사도만으로 위반을 확정하지 않습니다. 결과는 확인 대상으로 표시하고 규칙 준수 판단은 교사가 남깁니다.
- 기본 종료 후 저장 유예를0으로 유지합니다. 선택 활성화 시에도 실제 마감 기준을 사용하고 채점/리포트 이후 답안은 바꾸지 못합니다.
- 오래된 분석 작업의 성공/실패가 새 요청을 덮어쓰지 않도록 잠금과 요청 버전을 검사합니다.
- HTML 안내의 정리 결과 길이와 기존 DB 기본값을 보존하고, 잘린 내용이 저장되지 않도록 검증합니다.

## 압축에 함께 들어 있던 백엔드 변경

알림·사용자 설정/이름 변경·현재 비밀번호 확인 후 비밀번호 변경·평가 대기 중 수정/삭제·AI 허용5단계·복사/붙여넣기 이벤트·AI 사용 공개 기록 API도 소스와 테스트에 포함합니다. 실제 운영 계정/평가를 변경하거나 삭제한 적은 없습니다. 평가 삭제 API는 되돌릴 수 없으므로 프런트 확인 절차가 필요합니다.

기존 API는 유지합니다. 새 100점 Assessment API와 기존5×20/구0~4 리뷰 API는 별도 계약이므로 프런트는 새 화면에서 사용할 경로를 선택해야 합니다. 기존 리뷰·리포트 점수를 임의로100점 기준으로 덮어쓰지 않습니다. 요청 예시는 AI_GRADING.md와 Postman 컬렉션에 있습니다.
